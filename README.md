# Advanced Exploratory Data Analysis — Movies Dataset

A practical exploratory data analysis project demonstrating advanced use of **Pandas** to investigate patterns, distributions, relationships, and data quality in a movies dataset.

## 🎯 Objectives

- Inspect and understand the dataset structure.
- Clean and prepare movie data for analysis.
- Explore numerical and categorical variables.
- Identify useful patterns and relationships.
- Communicate findings through clear analysis and visualizations.

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Jupyter Notebook

## 📂 Project Workflow

1. Load and inspect the dataset
2. Data cleaning and preprocessing
3. Exploratory analysis
4. Statistical summaries
5. Visualization
6. Interpretation of findings

Data Analysis / Exploratory Data Analysis
